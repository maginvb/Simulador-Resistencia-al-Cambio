# Simulador · Resistencia al cambio

Simulador experiencial para participantes. Archivo único y autocontenido (`index.html`); no requiere dependencias.

## Publicar con GitHub Pages

1. Sube `index.html` y este `README.md` a la raíz del repositorio.
2. Settings → Pages → Source: **Deploy from a branch** → rama `main`, carpeta `/ (root)` → Save.
3. El simulador queda disponible en `https://<usuario>.github.io/<repositorio>/`.
